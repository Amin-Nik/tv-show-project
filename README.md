# tv-show-project

## this is a personal movie search website using Tvmaze API

• The project focused on developing a live search feature for TV shows

• The website could provide users a list of tv shows and all of their episodes

• Designed and coded with html, css and JavaScript only

• Technologies such as bootstrap and axios have been used
